Enhanced language detection system for iPad compatibility:
- Multiple detection sources (AppleLocale, AppleLanguages, AppleLocales)

3. LAYOUT CONSISTENCY GUARANTEE
Implemented PhoneLayoutWrapper system:
- All content wrapped in iPhone-dimension container
- Maximum width enforcement (393px)
- Consistent spacing and proportions
- Automatic centering on larger screens

4. CONFIGURATION ENHANCEMENTS
Updated app.config.js with explicit iPhone-only settings:
- UIUserInterfaceIdiom: 'phone' (forces iPhone mode)
- UIRequiredDeviceCapabilities: ['telephony'] (iPhone-only capability)
- UISupportedInterfaceOrientations~ipad: portrait only

TECHNICAL IMPLEMENTATION:

The solution works by:
1. Overriding React Native's Platform detection to always return iPhone
