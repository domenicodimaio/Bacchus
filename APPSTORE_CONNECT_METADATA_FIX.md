## 🔧 **COSA DEVI FARE SU APP STORE CONNECT**

### **A. Aggiornare Privacy Policy**

1. **Vai su App Store Connect** → La tua app
2. **App Information** → **General Information**
3. **Privacy Policy URL** → Inserisci:
   ```
   https://github.com/domenicodimaio/bacchus-urls/wiki/Privacy-Policy
   ```
4. **Salva**

### **B. Aggiornare App Description con EULA**

1. **Vai su App Store** → **App Information**
2. **App Description** → Aggiungi alla fine:
   ```
   
   Termini di Servizio: https://www.apple.com/legal/internet-services/itunes/dev/stdeula/
   ```

### **C. Alternativa: Usare EULA Field**

Se preferisci, puoi anche:
1. **App Information** → **App Review Information**
2. **EULA** → Seleziona **"Standard Apple EULA"**
